## 💡 Как редактировать страницы прямо на GitHub

1. Откройте любой `.md` файл в репозитории.
2. Нажмите на иконку карандаша ✏️ (**Edit this file**) в правом верхнем углу просмотра.
3. Внесите изменения (можно отмечать чекбоксы `[x]`, дописывать альбомы или локации).
4. Нажмите зелёную кнопку **Commit changes...** вверху справа — изменения сразу сохранятся.
